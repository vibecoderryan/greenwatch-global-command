# GREENWATCH: GLOBAL COMMAND

Ein Strategiespiel mit Weltkarte, Army, Navy, Air Force, Radar und Fog of War.

**Spielen:** `index.html` im Browser öffnen.

**GitHub Pages:** Nur `index.html` ins Hauptverzeichnis des Repositorys hochladen. Unter **Settings → Pages** `main` und `/ (root)` auswählen. `README.md` ist optional.

Version 0.3 · Für iPhone, iPad und Desktop optimiert · Offline spielbar.
