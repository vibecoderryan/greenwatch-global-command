# GREENWATCH: GLOBAL COMMAND v0.9

Weltweites Strategiespiel mit Radar, Army, Navy und Air Force. Optimiert für iPhone und iPad.

**Spielen:** `index.html` öffnen oder alle Dateien ins Hauptverzeichnis deines GitHub-Pages-Repositories hochladen.

**Steuerung:** Einheit direkt auf der Karte antippen → Aktion wählen → Ziel antippen. Schiffe, Flugzeuge und Armee haben eigene Symbole.

**Neu:** Automatische FLAK und Raketenabwehr, eigene Flugzeuge im Radar, schwächere KI und kompakte Touch-Befehle.

**App:** In Safari über „Teilen → Zum Home-Bildschirm“ hinzufügen.
