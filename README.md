# GREENWATCH: GLOBAL COMMAND v0.5

Militärisches Weltstrategiespiel mit Radar, Fog of War, Eroberungen und Touch-Steuerung für iPhone und iPad.

## Auf GitHub hochladen

Alle Dateien aus dieser ZIP **einzeln in das Hauptverzeichnis** des Repositories hochladen. Keine Ordner erforderlich. In GitHub unter **Settings → Pages → Deploy from a branch → main → / (root)** veröffentlichen.

## Spielen

GitHub-Pages-Adresse im Browser öffnen. Auf iPhone/iPad in Safari **Teilen → Zum Home-Bildschirm** wählen, um das App-Icon zu verwenden.

Spielstände werden lokal im Browser gespeichert. Internet wird beim ersten Laden benötigt; danach sind die Spiel-Dateien für Offline-Nutzung vorgesehen. Die Offline-Verfügbarkeit kann durch Browser-Cache-Löschungen entfallen.
